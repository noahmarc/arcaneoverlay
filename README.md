# Arcane Overlay

A D&D 4e battle-grid overlay with real-time multiplayer, fog of war, dice rolling, character sheets, an inventory system, and a searchable bestiary.

## Downloads

See the **[Releases](https://github.com/noahmarc/arcaneoverlay/releases)** page for the latest builds.

- **🍎 macOS native** — `ArcaneOverlay-mac.zip` — unzip and drag `ArcaneOverlay.app` into `/Applications`.
- **💻 Portable (Mac · Windows · Linux)** — `ArcaneOverlay-portable.zip` — requires Python 3. Double-click `start-mac.command`, `start-windows.bat`, or run `start-linux.sh`.

See the `README.txt` inside the portable bundle for full setup instructions.

## Multiplayer

One player hosts (creates a room); others join with the room code. All players must be on the same local network. The host's firewall must allow inbound connections on port 8765.
